## 2. 三条主链路的实测数据

| 链路 | 操作 | 结果 |
|---|---|---|
| 截图识别 | 上传 `word-list.png`（1080×1920） | 百度 OCR 识别 7 行，抽出 6 个单词，0 个错字，耗时约 2 s；同一张图第二次 14 ms（命中 `ocr_cache`） |
| 文章生成 | 复习模式 / C1 / 5 段 / 5 题 | 生成 347 词文章，5 段、5 题、15 个目标词全部出现在正文，耗时约 16 s |
| 点词查词 | 点击 `ledger` | 内置词典命中，返回 `/ˈledʒə/ n. 分类帐，分户总帐，盖墓石板，横木`，耗时 < 50 ms |
| 点词查词（未收录） | 拖选 `more than` | 返回 404 + `canAskModel:true`；点「问模型查一下」后得到「超过；多于；不仅仅是」 |

## 4. 已知不足（如实记录）

| 项 | 现状 | 原因 |
|---|---|---|
| 文章生成偶发结构不合格 | 有校验兜底，需要重试一次 | 大模型输出不稳定，已在提示词里约束 JSON 结构并加 `ArticleValidator` |
| 长截图（多屏拼接）识别 | 只支持单屏 | 需要切片 + 去重，工作量大，未做 |
| 移动端 | 只做到 720 px 断点，未做原生适配 | 定位是桌面端工具 |
| 并发 | 未做压测，单机自用场景 | 课程作业定位 |
| `ocr_cache` 清理 | 无过期策略 | 数据量小，暂不需要 |
