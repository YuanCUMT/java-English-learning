# 每日阅读项目修改约束

用途：为本课程工程维护提供上下文；是项目规约文档，不代表已经在某个 Agent 平台安装的插件。
技术：Java 21 源码目标、Spring Boot 3.3.5、MyBatis、Thymeleaf、MySQL；可选 H2 独立体验配置。
入口：README、docs/api.md、docs/er.md、acceptance.md、eval-set.md。

约束：
- 保留用户数据与私有配置，不输出 Key。付费调用只能由用户明确发起，验证使用桩或隔离环境。
- 业务数据必须按 user_id 过滤；非安全方法带会话 CSRF；错误 HTTP 状态与 JSON 契约同步。
- OCR 模拟结果明确标注且不缓存；确认前默认不保存。
- 复习覆盖至少 ceil(0.8N)，真题至少 min(15,N)；短语整串匹配，单词按词形表关系；不做前缀猜测。
- 结构或覆盖失败不得写库；文章落库事务需真实数据库验证；模型 HTTP 调用在事务外。
- 同步修改源码、测试、规约和报告；不能把未运行、桩验证或样例结果写成真实云实验。
- 常规初始化不可清库，示例不可覆盖已有当天 review 文章。
- 修改源码后更新 app JAR；启动只绑定回环地址。不要批量停止 Java 或 MySQL 进程。

当前目录不含 Git 元数据，不能将不存在的提交历史写为证据。实际修改记录和验收结果位于 docs/verification。数据库结构变更先保留数据并准备迁移，不自动执行破坏性操作。
